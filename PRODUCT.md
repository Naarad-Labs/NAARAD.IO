# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Naarad helps travellers discover routes across India, explore places through stories and use maps/listening on a walk. Creators can keep local story drafts. Existing catalogue, route data and honest availability disclosures are the product evidence; do not invent published narration, GPS surveying, offline coverage or account readiness.

## Operating context
The public site is static/prerendered and hosted on GitHub Pages at naarad.io, with a plain-JavaScript client, Leaflet maps, device-local Journey and draft stores, service worker/offline behavior and device read-aloud fallback. The separate NAARAD-APP account/backend project is not part of this redesign.

## Confirmed constraints
The user approved the map-first redesign proposal on 2026-11-04 and requested GSAP, Lenis and React Bits. Preserve functionality, public URLs, existing state and permissions, licensed imagery/credits, native map interaction, keyboard/screen-reader access and reduced motion. Preserve app.naarad.io and DNS; no backend or account activation. New public deployment requires a separate release decision.

## Brand and direction
Retain Naarad's name and recognizable orange/navy identity. The user selected a compact, practical, outdoor-focused map-first experience. Visual decisions belong in the surface brief and the final DESIGN.md, not product claims.
