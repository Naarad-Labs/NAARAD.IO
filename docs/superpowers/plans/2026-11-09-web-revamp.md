# Web Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dependency-free dithered background, apply it across the site's hero, header bands and footer, and embed the intro video and route-tracker visual.

**Architecture:** One ES module `app/dither.js` with pure, node-testable helpers plus a WebGL mount function, loaded from `app/main.js` and attached to elements carrying `data-dither`. Markup changes go in `app/shell.html` and `app/views/*.js`; pages are regenerated by `scripts/build-site.mjs`. Brand colours map onto existing tokens in `app/base.css`.

**Tech Stack:** Vanilla JS (ES modules), WebGL1, CSS, `node --test`, Playwright (existing `e2e/`).

**Spec:** `docs/superpowers/specs/2026-11-09-web-revamp-design.md`

## Global Constraints

- No new runtime dependency, no framework, no build step beyond `scripts/build-site.mjs`.
- Keep fonts: Playfair Display and DM Sans (spec section 6). Do not touch `app/fonts/`.
- Orange #F26A1C is fills/dither only. Orange text keeps `--orange-text` (#b04512). Body text over any dither keeps contrast >= 4.5:1.
- Edit `app/shell.html`, `app/views/*.js`, `app/*.css`; never hand-edit the generated pages.
- Any new or changed precached file means bumping `VERSION` in `sw.js` (now `v44`). Video files are NOT precached.
- `bash scripts/verify.sh` must pass before the final commit (`VERIFY_ALLOW_UNCOMMITTED=1` while uncommitted).
- `prefers-reduced-motion` and no-WebGL both fall back to a static gradient in the same colours.

## Review Focus

- WebGL context lost or unavailable mid-session: page stays usable with the static gradient.
- Element resized or rotated: canvas resizes without stretching or a blank frame.
- Offscreen or hidden tab: animation loop stops, restarts on return.
- Unknown `data-dither` value: falls back to the default palette, no throw.
- Missing video or mockup asset: section is omitted, no broken element or layout gap.

### Task 1: Dither module (pure helpers + mount)

**Files:**
- Create: `app/dither.js`
- Test: `tests/dither.test.mjs`

**Interfaces:**
- Produces:
  - `PALETTES: { navy:{back:string,front:string}, sand:{...}, forest:{...} }`: hex colours; `navy` = `#0B1D3A`/`#F26A1C`, `sand` = `#F2E8DB`/`#E4D9C3`, `forest` = `#1E5B46`/`#F2E8DB`.
  - `pickPalette(name: string | null): {back:string,front:string}`: returns `PALETTES.navy` for unknown or null.
  - `bayer4(x: number, y: number): number`: ordered-dither threshold in [0,1) from the 4x4 Bayer matrix.
  - `shouldAnimate(env: {reducedMotion:boolean, hasWebGL:boolean}): boolean`
  - `mountDither(el: HTMLElement, opts?: {palette?:string, scale?:number, speed?:number}): () => void`: appends a `<canvas class="dither-canvas" aria-hidden="true">` as first child of `el`, returns a teardown function. Never throws; on no-WebGL sets `el.dataset.ditherFallback = "1"` and appends nothing.

- [ ] **Step 1: Write failing tests** in `tests/dither.test.mjs`: `pickPalette(null)` and `pickPalette("nope")` deep-equal `PALETTES.navy`; `pickPalette("sand")` equals `PALETTES.sand`; `bayer4` returns 16 distinct values over a 4x4 grid, all in [0,1), and `bayer4(4,4) === bayer4(0,0)`; `shouldAnimate({reducedMotion:true,hasWebGL:true}) === false`, `shouldAnimate({reducedMotion:false,hasWebGL:false}) === false`, `shouldAnimate({reducedMotion:false,hasWebGL:true}) === true`; `mountDither` with a stub element whose `ownerDocument.createElement('canvas').getContext` returns null sets `dataset.ditherFallback === "1"` and returns a function.
- [ ] **Step 2: Run** `node --test tests/dither.test.mjs`. Expected: FAIL (module missing).
- [ ] **Step 3: Implement** the interfaces above in `app/dither.js`. Fragment shader: animated value noise -> `step(bayer, v)` -> mix(back, front). Render at `devicePixelRatio / scale` resolution (default scale 3, speed 0.15). Loop uses `requestAnimationFrame`, paused via `IntersectionObserver` and `document.visibilityState`. Handle `webglcontextlost` by tearing down and setting the fallback flag. Resize via `ResizeObserver`. When `shouldAnimate` is false, draw one frame only.
- [ ] **Step 4: Run** `node --test tests/dither.test.mjs`. Expected: PASS.
- [ ] **Step 5: Commit** `git add app/dither.js tests/dither.test.mjs && git commit -m "Add dependency-free dither module"`
