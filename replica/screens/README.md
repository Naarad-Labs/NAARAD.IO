# replica/screens

Screenshots of the original app, used by `/replica-diff` for the layout comparison. The images themselves are
**not committed** (see `.gitignore` here). `../screens-notes.md` describes each one.

To rerun the layout diff, put the files back here with these names:

| file | what it shows |
| --- | --- |
| `orig-m-map-wide.jpg` | Routes tab, map view, zoomed out, 14 results |
| `orig-m-map-chennai.jpg` | Routes tab, map view, searched "Chennai", 2 results |
| `orig-m-routes-list-top.jpg` | Routes tab, list view, top of the list |
| `orig-m-routes-list-scrolled.jpg` | Routes tab, list view, scrolled one card |
| `orig-m-home.jpg`, `orig-m-profile.jpg`, `orig-m-record-paused.jpg` | other tabs (outside the Discover slice) |

All are 1080x2400 Android phone screenshots of Komoot's app.
